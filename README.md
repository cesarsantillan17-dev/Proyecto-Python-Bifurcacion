
# Reto Semanal - Semana 5: Lógica de Bifurcación

## Descripción
Programa desarrollado en Python para implementar estructuras condicionales (`if`, `elif`, `else`) y funciones básicas.

## Objetivo
Determinar la validez de una palabra según su longitud y ubicar un punto dentro del plano cartesiano mediante sus coordenadas.

## Funcionalidades

### 1. Validación de palabras
- Solicita una palabra al usuario.
- Utiliza `len()` para determinar su longitud.
- Identifica si tiene entre 4 y 8 letras.
- Muestra un mensaje según el resultado.

### 2. Determinación del cuadrante cartesiano
- Solicita los valores de X y Y.
- Utiliza estructuras condicionales.
- Identifica los cuadrantes I, II, III y IV.
- Detecta puntos ubicados sobre los ejes o en el origen.

## Tecnologías utilizadas
- Python 3
- Visual Studio Code

## Ejecución

Abrir la terminal y ejecutar:

```bash
python reto_bifurcacion.py
```
